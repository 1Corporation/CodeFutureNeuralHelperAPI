# CodeFutureNeuralHelperFrontend
Кодовое название "Потемкинские деревни"

## Описание

Фронтенд-интерфейс для чата с нейросетью в желто-оранжевых тонах. Проект разработан на Vue 3 с использованием Vite.

## Функциональность

- Интерфейс чата с поддержкой текстовых сообщений
- Визуальное отображение состояния загрузки при ожидании ответа
- Адаптивный дизайн в желто-оранжевой цветовой гамме
- Готовые методы для создания сообщений пользователя и нейросети
- Подготовленная структура для интеграции с API

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр продакшен-сборки
npm run preview
```

## Интеграция с API

Для интеграции с вашим бэкендом используйте файл `src/services/apiService.js`, который содержит заготовки методов для взаимодействия с API нейросети.

## Структура проекта

```
/
├── public/           # Статические файлы
├── src/
│   ├── assets/       # Ресурсы (стили, изображения)
│   ├── components/   # Компоненты Vue
│   ├── services/     # Сервисы для работы с API
│   ├── views/        # Компоненты для маршрутов
│   ├── router/       # Настройка маршрутизации
│   ├── App.vue       # Корневой компонент
│   └── main.js       # Точка входа
├── index.html        # HTML-шаблон
└── vite.config.js    # Конфигурация Vite
```

## Кастомизация

Основные цвета и стилевые переменные определены в файле `/src/assets/styles/main.css`. Для изменения цветовой схемы отредактируйте значения переменных в `:root`.
